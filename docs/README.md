## Guides vs Reference

Two things named `hooks-and-ways` serve different layers:

- **`hooks-and-ways/`** (directory): guides for practitioners. "How do I create a way?" "How does matching work?"
- **`hooks-and-ways.md`** (file): reference for contributors. Hook events, scripts, switches and internal mechanics; the diagrams are in architecture.md and the fire rule in hooks-and-ways/engine-reference.md.
