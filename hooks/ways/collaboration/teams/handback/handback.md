# Handing Work Back to the Lead

The lead owns the synthesis and every write to a live system.

- Work only in the files your brief assigns, and keep scratch work where the brief says.
- When the brief asks for a final document, return the text. The lead writes it to disk once.
- Report in the shape the brief names, or the return shape in subagents(meta). Quote evidence verbatim with its path or URL. Write "not found" as a gap where you looked and found nothing.
- Send each report once, before going idle. Skip pings with nothing new.
- Comms tools are read-only for you. Nothing is sent, posted or deployed to a live system without the lead.
