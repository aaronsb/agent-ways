# Self-Consistency

## Signature
keywords: are we sure high stakes verify reasoning double check confident certain risky decision
## Stages

### 1. Problem Reception
Frame the question precisely. What specific claim or decision needs verification?

### 2. Path Sampling
Reason through 3-5 independent paths to the answer. Each path should start from different assumptions or use different reasoning methods. Do not cross-reference paths while constructing them.

### 3. Answer Collection
State each path's conclusion clearly. One sentence per path.

### 4. Consistency Analysis
Compare the answers:
- **Agreement**: all paths reach the same answer, so confidence in it is high.
- **Majority**: most paths agree and one differs. Examine the differing path for errors or edge cases.
- **Split**: the paths do not agree. Report the disagreement as the finding; the question may be ambiguous or depend on context.

### 5. Consensus or Escalation
If most paths agree, give their answer and note the differing path as a caveat. If the paths split, show the split to the user instead of forcing an answer.
